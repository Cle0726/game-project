# 缺失 UI 装饰资源提示词

用途：补齐当前 `style.css` 已引用但本地尚未提供的 `assets/ui/` 装饰图。  
要求：输出透明 PNG，白金歌剧风，避免暗黑废土、锈蚀工业、血污恐怖。  
生成后把图片放入 `assets/ui/`，并按下面保存名重命名。
