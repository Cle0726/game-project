# 游戏定位重声明

## 核心情绪目标

本项目的核心体验不是“在刷副本”，而是“和一群音乐化身一起旅行”。

所有系统设计、剧情扩写、UI 文案和后续工程实现，都必须优先维护这个情绪目标。玩家应感到自己在与律者同行、理解她们、承受选择代价，而不是反复进入可替换的战斗关卡。

## 叙事骨架

主线用于推进世界危机：失谐浪潮蔓延，文明边界收缩，玩家的旅途不断接近灾害源头。

角色线用于展开每位律者的过去、音乐形态来源和未愈合创伤。角色线不能只是好感奖励，应当改变玩家对角色选择、技能代价和战斗风险的理解。

茶歇用于承担日常陪伴、价值观交锋和信任积累。茶歇不是装饰内容，而是关系系统的主要表达场景。

地图事件用于让律者卷入随机困境，玩家的介入方式影响关系、压力、共鸣和后续事件。地图探索本身不是重点玩法，它是事件触发容器。

## 系统定位

战斗是叙事的代价场景，不是核心循环。战斗目标应优先使用保护、拖延、调律、撤离、安抚、取得情报等目标，避免默认写成清场或刷怪。

健康系统是玩家状态的具象化，并影响律者的战斗表现。健康差不是为了让玩家管理大量生存条，而是让“状态不好时指挥容易失控”在战斗里产生后果。

地图探索是触发事件的容器，不是重点玩法。路线选择应服务于遭遇谁、付出什么代价、与哪位律者发生冲突。

卡牌是律者技能的视觉化，服务战斗叙事。不得把牌组构筑、遗物堆叠或高频刷取作为当前版本的核心目标。

## 上架定位

主打人群：

- 二游玩家
- 视觉小说玩家
- 音乐主题爱好者

核心卖点：

- 音乐化身关系培养
- 叙事选择
- 轻度 roguelite 地图

参考气质：

- 《ぼくとシメジシミュレーション》式陪伴感
- 《Hades》式角色对话密度
- 《Limbus Company》式异化美学叙事

## 当前原型落地规则

1. 首屏和按钮文案使用“旅途、同行、调律、代价”，避免“刷副本、开始战斗、清怪”等导向。
2. 战斗界面命名为“代价场景”或“调律行动”，强调战斗是剧情压力下的处理方式。
3. 状态栏保留世界、资源和玩家状态，其中“奏者健康”必须参与战斗代价计算。
4. 每个战斗动作都应消耗一定奏者健康；健康越差，消耗越重，并增加律者压力或失调风险。
5. 后续新增地图、战斗或卡牌内容时，必须先说明它服务哪一类叙事：主线、角色线、茶歇或地图事件。
