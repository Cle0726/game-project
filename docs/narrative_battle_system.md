# 战斗系统：服务叙事版本

## 定位

战斗是叙事代价的具象场景，不是重复数值检验。每场战斗必须有故事意义，必须说明为什么打、打完后改变什么、是否存在回避方式。

每场战斗开始前必须声明：

- 为什么打这场战斗。
- 打完之后发生什么。
- 可以不打吗；如果可以，回避代价是什么。

## 简化战斗流程

战前选择：

1. 玩家选择 2 名律者出战。
2. 系统显示本次战斗特殊条件，例如“洛温信任不足，有失调风险”。
3. 如果剧情允许，玩家可以回到调律台先建立关系再来，但会付出世界、城邦或资源代价。

战斗结构：

- 每场 3-5 轮。
- 每轮玩家选择一名律者行动，或使用奏者能力。
- 技能按钮显示技能名、行动点代价、奏者健康代价和一句效果说明。
- 行动前判定是否触发失调。
- 行动结果用 2-3 句文本呈现，并包含角色状态或台词。
- 敌人按“被污染的音乐结构”行动，并在回合结束后显示下一轮意图预告。

## 敌人行动规则

噬响体的行动模式遵循它吞噬的音乐记忆。它们不是普通怪物，而是污染后的演奏结构。

设计要求：

- 每回合结束显示下一轮意图预告。
- 玩家可用特定技能打断节拍，延后或改变敌人行动。
- Boss 战前必须描述其“扭曲的演奏方式”。

## 独演

独演是律者极限技能，是角色个人高光时刻，不是普通大招。

触发条件：

- 每场战斗拥有一个共鸣积累槽。
- 共鸣槽满，或特殊剧情触发时，可释放独演。

演出流程：

1. 背景色变化，使用该律者专属色。
2. 全屏过渡，画面短暂变暗。
3. 独演文字描述 100-150 字，使用第一人称或强贴近奏者感知的写法。
4. 效果结算融入文字。
5. 角色后台词 1-2 句，体现当下状态和价值观。

独演文本必须包含：

- 音乐意象。
- 身体感知。
- 一句律者内心独白。
- 效果描述。

## 当前原型落地状态

1. 教程战“灯渠边的断拍”已改为战前选择 2 名律者。
2. 战前界面声明叙事理由、战后推进和回避代价。
3. 战斗按钮显示行动点、奏者健康代价和简短效果。
4. 战斗 UI 显示敌人下一轮意图预告。
5. 每场战斗有独演共鸣槽。
6. 槐序已实现独演“宿命三拍”的文字与视觉化演出。
