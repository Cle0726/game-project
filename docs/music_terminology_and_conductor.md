# 音乐化命名体系与奏者机制

## 音乐化命名体系

| 术语 | 含义 | 设计逻辑 |
|---|---|---|
| 奏者（Conductor） | 玩家角色 | 不是演奏者，是调配者 |
| 律者（Musicart） | 可操控的音乐化身 | 音乐之力的人格化 |
| 失谐潮 | 世界末日灾难 | 音乐被污染后扩散 |
| 共鸣值 | 律者对奏者价值观的认同深度 | 不是好感度，是共振深度 |
| 失调 | 律者的精神不稳定状态 | 和失谐对应的角色内部状态 |
| 独演 | 律者释放极限技能 | 个人高光时刻，不是大招 |
| 乐装 | 律者的装备 | 乐器化的战斗装备 |
| 音枢 | 核心战斗符文 | 关键音节，改变技能结构 |
| 和声符 | 辅助战斗符文 | 叠加在独演上的修饰 |
| 音芯 | 战斗资源 | 音乐能量的晶体化 |
| 粮药 | 生存资源 | 身体性生存的具象 |
| 调律台 | 跑图休息点 | 不是篝火，是音准校正站 |

## 音乐情绪到角色设计映射

写角色时不能把曲名直接贴到角色身上，必须先提炼音乐情绪，再映射到视觉、武器、独演和台词。

| 情绪类型 | 配色 | 武器 | 独演感受 | 台词规则 |
|---|---|---|---|---|
| 热烈激昂 | 暗红 + 铜金 | 冲击型 | 爆发膨胀感 | 直接、挑衅、不掩盖欲望 |
| 悲怆沉郁 | 靛蓝 + 银灰 | 穿刺型 | 缓慢涨潮感 | 隐喻、省略号、说一半留一半 |
| 神圣庄严 | 纯白 + 金 | 结界型 | 垂直光柱感 | 简洁，判断性，不解释 |
| 诡谲游移 | 烟紫 + 金绿 | 变形型 | 镜像扭曲感 | 悖论、反问、拒绝结论 |
| 轻快俏皮 | 水蓝 + 柠黄 | 投掷型 | 快切多段感 | 跳跃、调侃、突然认真一句话 |
| 宏大史诗 | 深蓝 + 暗金 | 重击型 | 地鸣扩散感 | 有压迫感，少说，说必中心 |

## 奏者身份

玩家扮演“奏者”，是能感知失谐偏差的特殊人类。奏者不直接战斗，而是通过指挥律者发动技能。奏者健康决定指挥质量：健康越差，指挥越混乱，技能健康代价越高。

主角年龄感为 17—19 岁。开局身份是流动修理车队“昼夜巡演团”的随行者，擅长看谱、调音、简单弹奏和修理旧乐器。主线目标是在被阿缇娅抛出的指挥棒选中后，前往白谱院，寻找异常契约和律者状态的真相。

男性默认名为凛澈，可改名；女性默认名为凛纱，可改名。二者都不是成熟指挥官，而是被契约推上舞台的普通修谱者。

奏者开局不是成熟的华丽指挥家。初始形象应是简单、干净、轻便、偏日常旅行感的普通少年/少女：会弹琴、会修谱、会搬运旅途物资，但尚未准备好被命运推上舞台。主角真正的指挥家感来自右腕契约刻痕、接住指挥棒的手、战斗时痛到发抖却不松开的动作，以及看见钢琴时无法移开视线的表情。

初始服装禁用长风衣、大披风、过度华丽礼服、复杂军装、高级指挥官轮廓，以及开局持有指挥棒。

奏者性别在游戏开始时选择：

- 男
- 女
- 未标注

## 性别对律者指挥的影响

男性奏者指挥男性律者时存在失调摩擦。男性律者的音乐人格带有自主节奏驱动，在共鸣不足或压力过高时拒绝被外部节奏完全覆盖。

当前原型已实现的触发条件：

| 条件 | 失调概率 |
|---|---:|
| 男性律者共鸣值 < 40 | 20% |
| 男性律者共鸣值 < 25 | 40% |
| 男性律者压力 > 70 且共鸣值 < 50 | 60% |

失调发动效果：

- 技能效果随机，可能提前发动、偏向保护、或直接空过。
- 奏者健康代价随机，可能低于原代价，也可能达到约 2-3 倍。
- 失调发动后，该律者本场战斗压力 +10。

女性奏者指挥任何律者时无额外失调摩擦。

未标注奏者指挥任何律者时无常规摩擦，但有极低概率触发“共鸣超载”：收益更高，同时健康代价随机。

## 双律者上场规则

每次战斗最多带 2 名律者。玩家每次行动选择哪名律者行动，而不是自动轮流。带谁、谁先行动，是战略决策。

共鸣值高的律者更容易配合奏者，能减少失调概率并为后续协奏技能提供条件。两名律者之间存在协奏关系，特定组合可触发协奏技能。

## 当前原型落地状态

1. 新旅途开始前必须选择奏者性别。
2. 旧存档会补齐三维关系字段；历史“槐序信任”若存在，会同时用于初始化“槐序信任”和“槐序共鸣”。
3. 洛温已作为男性律者接入失调摩擦判定。
4. 未标注奏者已接入低概率“共鸣超载”。
5. 战斗动作已标记行动律者，后续可扩展为 2 名律者编队选择。
