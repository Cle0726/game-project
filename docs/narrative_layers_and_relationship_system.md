# 叙事四层结构与共鸣关系系统

## 四层叙事结构

### 第一层：主线剧情

主线用于推进世界危机：失谐潮蔓延、文明边界收缩、阵营压力上升。主线节点由特定地图节点或场景到达自动触发。

主线选择后果主要影响：

- 城邦稳定度
- 世界失谐度
- 阵营声望

主线不依赖律者关系，不会因为信任低而锁死。但律者的信任、共鸣、压力会影响她在主线里的台词、行为细节和是否触发隐藏台词。

主线剧情节点格式：

- 场景描写，100-300 字，包含环境和气氛。
- 若干轮对话，允许律者、NPC、玩家内心交替出现。
- 1-3 个关键选择。
- 选择后果，包含变量变化和下个场景 ID。
- 隐藏台词条件，例如某律者信任达到阈值后追加一句台词。

### 第二层：律者个人故事

个人故事用于展开律者的过去、音乐人格来源、未愈合创伤，以及她与世界失谐的关联。个人故事不直接给结论，玩家应通过片段自行判断。

每名律者个人故事共 3 章：

- 第 1 章，共鸣 30：她是谁，她从哪里来。
- 第 2 章，共鸣 60：她为什么是现在这个样子。
- 第 3 章，共鸣 90：她和世界失谐的深层关联，会影响主线结局走向。

触发方式：共鸣达到阈值后，下次进入地图节点时自动提示。玩家可选择立即查看，或稍后在调律台/地图节点进入。

### 第三层：茶歇互动

茶歇承担日常陪伴、价值观交锋、失败后的修复与隐藏台词开放。茶歇不是菜单附属功能，而是关系系统的主要表达场景。

触发时机：

- 地图上的调律台节点。
- 战斗后的结算阶段。
- 生活日的傍晚时间段。

茶歇语境：

| 语境 | 触发条件 | 律者基调 | 玩家风险 |
|---|---|---|---|
| A 平时闲聊 | 无压力场合 | 放松但仍有戒备 | 探索喜好 |
| B 关键剧情前 | 主线节点前 | 情绪有暗涌 | 影响进入剧情状态 |
| C 战斗失败后 | 失败结算后 | 回应失败代价，不一定安慰 | 影响律者对玩家能力判断 |
| D 高压力 | 压力 > 70 | 抗拒、疲惫，可能拒绝话题 | 强聊创伤触发失调预警 |
| E 高信任 | 共鸣 > 70 | 开放隐藏台词 | 影响隐藏剧情分支 |

当前静态原型先实现文字按钮版茶歇；后续接入 DeepSeek API 时，必须保留当前上下文、语境和关系变量作为输入约束。

### 第四层：地图事件

地图探索不是重点玩法，而是事件触发容器。随机事件提供可玩性和旅途密度。

事件比例：

- 叙事事件 80%：文字选择，影响变量。
- 迷你游戏事件 20%：节拍判断、碎片解读、音色辨识。

叙事事件类型：

- 律者卷入型：某律者遭遇困境，玩家选择如何介入。
- 世界观型：遭遇普通 NPC，了解世界现状。
- 道德困境型：资源或关系二选一。
- 隐藏历史型：发现失谐起源碎片。

第一章事件池共 20 个事件，每次跑图随机抽取 5-8 个。E016-E020 是高关系解锁事件，需要对应律者信任或共鸣达到阈值。

## 共鸣关系系统

角色不是被攻略，而是在判断玩家是否把她当工具。关系是双向判断，不是奖励条。

每名律者有三个关系维度：

| 维度 | 范围 | 含义 | 影响 |
|---|---:|---|---|
| 信任 Trust | 0-100 | 律者对奏者决策的信赖程度 | 男性律者失调概率、特殊台词、战斗配合效率 |
| 共鸣 Resonance | 0-100 | 律者对奏者价值观的认同程度 | 个人故事解锁、隐藏分支、独演效果加成 |
| 压力 Pressure | 0-100 | 律者当前心理负担 | 茶歇语气、失调概率、指令拒绝 |

### 槐序判断标准

+共鸣行为：

- 玩家承认自己不确定。
- 玩家保护无关紧要的人而牺牲效率。
- 玩家对她的过去表示好奇，但不追问。
- 战斗失败后玩家没有第一时间怪她。

-共鸣行为：

- 玩家强行要求她服从。
- 玩家用结果评判她的选择。
- 玩家把她和其他律者对比。

+信任行为：

- 高风险时玩家征询她的意见。
- 玩家告诉她为什么做选择，而不是只下命令。

压力来源：

- 战斗中被迫消耗大量体力。
- 主线选择让她价值观受挫。
- 茶歇触及创伤话题。

### 洛温判断标准

+信任行为：

- 玩家决策稳定。
- 资源不足时优先保证队伍安全。
- 注意到他压力高并主动让他休息。

-共鸣行为：

- 过度依赖他当盾。
- 在他面前回避代价。

失调特别触发：信任 < 30 且连续多次让他执行错误指令时，提高失调概率。

### 伊芙白判断标准

+共鸣行为：

- 地图上选择绕路探索。
- 事件中帮助信息更少的一方。
- 注意到她疲惫时减少战斗频率。

-信任行为：

- 接受表面解释，没有看穿她的试探。

## 关系档位

信任档位：

- 0-29 陌生：男性律者失调概率高，女性律者可能拒绝部分行动。
- 30-59 认识：基本正常，偶有失调，茶歇开放基础层。
- 60-79 信任：失调概率低，战斗配合加成，茶歇开放第二层。
- 80-100 深信：无失调，协奏概率提高，解锁专属战斗台词。

共鸣档位：

- 0-29 陌生人：基础对话，表面信息。
- 30-59 同行者：个人故事第 1 章解锁。
- 60-79 旅伴：个人故事第 2 章解锁，地图事件增加律者视角。
- 80-100 共鸣者：个人故事第 3 章解锁，影响主线结局分支。

压力档位：

- 0-39 稳定：正常行为。
- 40-69 紧绷：茶歇语气变短，轻松话题回应变冷。
- 70-89 高压：拒绝部分指令，茶歇可能触发高压事件。
- 90-100 失调边缘：战斗中主动发动独演，消耗自身，不受奏者控制。

## 当前原型落地规则

1. 主线场景可配置 `hiddenDialogues`，按关系变量追加隐藏台词。
2. 地图节点可配置 `isMapNode`，进入时检查个人故事解锁。
3. 茶歇先以文字按钮版实现，保留语境、关系变量和后续 API 接入点。
4. 第一章事件池以数据表实现，包含 20 个事件和 20% 迷你游戏事件。
5. 战斗失调概率使用“信任”，个人故事解锁使用“共鸣”，压力影响茶歇和失调风险。
