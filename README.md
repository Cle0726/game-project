# 宿命回响：残响之途

《宿命回响：残响之途》是一款以**音乐主题世界观、角色关系推进与叙事选择**为核心的剧情向游戏原型项目。项目围绕“与音乐化身同行、在失调世界中承担选择代价”的体验展开，强调角色陪伴、章节叙事、事件驱动探索与具有情绪后果的战斗表达。

当前仓库用于持续同步项目原型开发进展，包括前端界面、章节入口、世界地图、战斗测试、角色与场景资源、数据外置化整理，以及基础后端服务等内容。

## 项目概述

本项目聚焦于构建一个以“同行感”为核心的叙事体验：

- 以**音乐化身（Musicart）**与指挥者的关系为核心推动情节
- 通过**章节剧情、地图事件与茶歇互动**塑造角色弧光
- 以**轻度地图探索**承载路线选择、风险代价与遭遇分歧
- 将战斗设计为**剧情压力下的调律行动**，而非单纯数值刷图

相较于传统以副本循环为中心的结构，本项目更强调人物情绪、关系演变与世界状态变化对玩家体验的持续影响。

## 核心设计方向

项目当前强调以下设计原则：

1. **叙事优先**：主线、角色线与事件系统共同推动体验，不以高频刷取为目标。
2. **关系驱动**：角色互动、信任积累与价值观碰撞是内容推进的重要部分。
3. **代价可感知**：战斗、探索与选择都应体现状态压力与后果反馈。
4. **音乐主题统一**：世界观、美术、角色设定与系统表现围绕“音乐 / 失调 / 调律”展开。

## 本地开发

### 环境准备

项目包含前端与 Python 后端，首次启动前请先安装依赖。

```bash
npm install
pip install -r server/requirements.txt
```

### 启动开发环境

```bash
npm run start
```

默认会同时启动：

- Vite 前端开发环境
- FastAPI 后端服务（`server/main.py`，默认端口 `8000`）

### 常用测试入口

```bash
npm run index:test
npm run battle:test
npm run portrait:test
npm run worldmap:test
```

## 仓库结构

建议初次浏览时优先关注以下目录与文件：

- `index.html`：主游戏入口结构
- `src/`：前端测试入口与相关模块
- `server/`：后端服务、认证与数据模型
- `assets/`：角色、CG、背景、敌方与 UI 等资源
- `docs/`：项目定位、叙事设计、技术说明与资产规划
- `scripts/`：资源校验、数据守卫与辅助脚本

## 适合的阅读方式

如果你想快速理解这个项目，推荐按以下顺序浏览：

1. 阅读本 README，了解项目定位与当前阶段
2. 查看 `docs/` 中的定位与技术说明文档
3. 通过 `npm run index:test` 或其他测试入口体验当前原型
4. 再进入 `src/`、`server/` 与 `assets/` 了解实现与内容组织方式
