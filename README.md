# 宿命回响：残响之途

《宿命回响：残响之途》是一款以**音乐化身、关系培养、叙事选择**为核心的剧情向游戏原型项目。当前版本聚焦于“和角色同行、在失调世界中做选择”的体验，而不是纯刷图或数值堆叠。

## 当前版本介绍

**版本状态：开发预览版（Preview / 2026-07）**

当前公开仓库主要包含以下内容：

- 主界面与章节入口原型
- 世界地图与事件驱动探索测试
- 战斗界面与调律行动测试
- 角色立绘、CG、背景、敌方与 UI 资源的持续补完
- 部分系统数据的外置化整理（便于后续维护与扩展）
- 基础后端服务与数据模型

当前版本更偏向**可游玩的持续开发原型**，用于逐步完善剧情、角色关系、地图事件与战斗表现。

## 项目定位

项目核心体验不是“刷副本”，而是：

> 和一群音乐化身一起旅行，理解她们、承担选择代价，并穿过失调世界留下的余响。

关键词：

- 叙事选择
- 音乐主题世界观
- 角色关系推进
- 轻度地图探索
- 战斗作为剧情代价场景

## 技术栈

前端 / 表现层：

- Vite
- React
- TypeScript
- PixiJS
- GSAP
- Howler
- Tone.js

后端 / 数据层：

- FastAPI
- SQLAlchemy
- Pydantic

## 本地启动

### 前端 + 后端联调

```bash
npm install
npm run start
```

默认会同时启动：

- Vite 前端开发环境
- FastAPI 后端服务（`server/main.py`）

### 常用测试入口

```bash
npm run index:test
npm run battle:test
npm run portrait:test
npm run worldmap:test
```

## 仓库说明

当前仓库会持续同步开发中的资源、数据整理与原型迭代内容。若你只是第一次浏览，建议优先从以下部分开始：

- `index.html`：主游戏入口结构
- `src/`：前端测试入口与相关模块
- `server/`：后端服务与数据模型
- `docs/`：项目定位、叙事设计与技术说明
